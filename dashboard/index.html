About the system

AVDF combines visual face evidence and 16 kHz audio evidence through cross-modal attention. Confidence and uncertainty determine whether a case is auto-accepted or sent to a reviewer.

Method and limitations

Model

EfficientNet-B0 visual encoding, WavLM-Base+ audio encoding with sensitive layer selection, bidirectional multi-head fusion, focal loss, MC Dropout or evidential uncertainty.

Datasets

FakeAVCeleb is intended for train/validation/test. AV-Deepfake1M and DFD are intended for cross-dataset testing only. Licensed data is not distributed with this repository.

DEMO MODE fixtures are not model predictions. Scientific metrics appear only after real result files are generated.
